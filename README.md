# AI-Virtual-Mouse

An AI-based virtual mouse that allows users to control a computer using hand gestures and eye movements.

## Features

- Index finger → Move cursor
- Thumb + index pinch → Drag
- Index + middle fingers → Scroll up
- Closed fist → Scroll down
- Pinky only → Precision mode
- Crossed fingers → Open Notepad
- OK sign → Voice typing
- Two open hands → Zoom
- Both eyes closed → Click
- One eye closed → Screenshot

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## How to Run

Install the required libraries:
```
pip install opencv-python mediapipe pyautogui numpy
```
Then run:
```
python VM.py
